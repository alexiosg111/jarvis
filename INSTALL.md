# Installation

Download the latest release of Jarvis Hub from the GitHub Releases page.

## Windows

Download the Windows installer (`.exe`):

```
https://github.com/alexiosg111/jarvis/releases/latest/download/Jarvis%20Hub-0.2.6-win-x64.exe
```

After downloading, double-click the `.exe` file to install Jarvis Hub.

## macOS

macOS builds are currently not available. Windows only for now.

## Finding the Latest Version

To find the latest version number, visit the [releases page](https://github.com/alexiosg111/jarvis/releases) and look for the most recent tag (e.g., `v0.2.6`).

## System Requirements

- **Windows**: Windows 10 or later (64-bit)
- **Disk Space**: ~100 MB

## Verification

After installation, launch Jarvis Hub from your Start menu (Windows). The app will open and be ready to use.
