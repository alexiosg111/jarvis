# Installation

Download the latest release of Jarvis Hub from the GitHub Releases page.

## Windows

Download the Windows installer (`.exe`):

```
https://github.com/YOUR_USERNAME/jarvis-hub/releases/latest/download/Jarvis%20Hub-<version>-win-x64.exe
```

Replace `<version>` with the latest version number (e.g., `0.1.2`).

Example for version 0.1.2:
```
https://github.com/YOUR_USERNAME/jarvis-hub/releases/latest/download/Jarvis%20Hub-0.1.2-win-x64.exe
```

After downloading, double-click the `.exe` file to install Jarvis Hub.

## macOS (Intel)

Download the macOS Intel disk image (`.dmg`):

```
https://github.com/YOUR_USERNAME/jarvis-hub/releases/latest/download/Jarvis%20Hub-<version>-mac-intel.dmg
```

Replace `<version>` with the latest version number (e.g., `0.1.2`).

Example for version 0.1.2:
```
https://github.com/YOUR_USERNAME/jarvis-hub/releases/latest/download/Jarvis%20Hub-0.1.2-mac-intel.dmg
```

After downloading, double-click the `.dmg` file to mount it, then drag Jarvis Hub to your Applications folder.

## Finding the Latest Version

To find the latest version number, visit the [releases page](https://github.com/YOUR_USERNAME/jarvis-hub/releases) and look for the most recent tag (e.g., `v0.1.2`).

## System Requirements

- **Windows**: Windows 10 or later (64-bit)
- **macOS**: macOS 10.15 (Catalina) or later (Intel)
- **Disk Space**: ~100 MB

## Verification

After installation, launch Jarvis Hub from your Start menu (Windows) or Applications folder (macOS). The app will open and be ready to use.
